All Conditionals Cheat Sheet (Zero - Third)

Zero & First Conditional

ความจริง & เป็นไปได้จริง

ใช้กับความจริงสากล หรือเหตุการณ์ที่มีโอกาสเกิดขึ้นจริงในอนาคต

Zero Conditional (ความจริงสากล/วิทยาศาสตร์)
If + Present Simple, Present Simple
e.g. If you freeze water, it becomes ice.
First Conditional (เป็นไปได้ในอนาคต)
If + Present Simple, will + V.1
e.g. If it rains, I will stay at home.

Second & Third Conditional

สมมติปัจจุบัน & เสียดายอดีต

ใช้กับเรื่องไม่จริงในปัจจุบัน หรือความเสียดายเหตุการณ์ในอดีตที่ย้อนเวลากลับไปแก้ไม่ได้

Second Conditional (ตรงข้ามความจริงปัจจุบัน)
If + Past Simple (V.2/were), would + V.1
e.g. If I had a lot of money, I would buy a mansion.
Third Conditional (ตรงข้ามความจริงในอดีต)
If + Past Perfect (had+V.3), would have + V.3
e.g. If she had studied, she would have passed.
