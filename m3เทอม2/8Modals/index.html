Obligation vs Prohibition

ความจำเป็น vs ข้อห้าม

ใช้บอกข้อบังคับตามกฎหมาย/กฎเกณฑ์ หรือสิ่งที่ห้ามทำเด็ดขาด

1. Obligation (จำเป็นต้องทำ)
• must (จำเป็นจากความรู้สึกตนเอง/กฎเหล็ก) + V.1
• have to / has to (จำเป็นจากกฎภายนอก) + V.1
e.g. Students must wear school uniforms.
2. Prohibition (ห้ามทำเด็ดขาด)
• mustn't / must not + V.1 (ผิดกฎหมาย/อันตราย)
e.g. You mustn't smoke in the hospital.

Advice vs Lack of Necessity

คำแนะนำ vs ไม่จำเป็น

ใช้เสนอแนะสิ่งที่ดี หรือบอกสิ่งที่ทำหรือไม่ทำก็ได้

3. Advice (การให้คำแนะนำ)
• should / ought to / had better + V.1
e.g. You should see a doctor if you feel sick.
4. Lack of Necessity (ไม่จำเป็นต้องทำ)
• don't have to / doesn't have to / needn't + V.1
e.g. It's Sunday; you don't have to get up early.
