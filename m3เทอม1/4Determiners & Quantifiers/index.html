Each vs Every

การชี้เฉพาะ

ใช้กับคำนามนับได้เอกพจน์เสมอ แต่มีจุดเน้นต่างกันเล็กน้อย

Each (แต่ละ - มองเป็นรายบุคคล)
Each student has a book.
Every (ทุกๆ - มองเป็นกลุ่มรวมทั้งหมด)
Every room is clean.

Either, Neither, None

การเลือก/ปฏิเสธ

ใช้สำหรับการเลือกหรือกล่าวถึงจำนวนที่จำกัด

Either / Neither (อย่างใดอย่างหนึ่ง / ไม่ใช่ทั้งสอง)
• Either (อย่างใดอย่างหนึ่งจาก 2)
• Neither (ไม่ใช่ทั้ง 2 อย่าง)
None (ไม่มีเลย - ใช้กับจำนวน 3 ขึ้นไป)
None of the students were late.
