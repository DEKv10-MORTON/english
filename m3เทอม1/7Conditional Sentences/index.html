If-Clause Masterclass Cheat Sheet

ทำความเข้าใจโครงสร้างประโยคเงื่อนไขทั้ง 4 ประเภทหลัก สังเกตความเชื่อมโยงระหว่าง Tense ใน If-Clause และ Main Clause!

Type 0 & Type 1

ความจริง & เป็นไปได้ในอนาคต

ใช้กับความจริงทางวิทยาศาสตร์ หรือสิ่งที่อาจจะเกิดขึ้นจริงในอนาคต

Type 0 (ความจริงสากล)
If + Present Simple, Present Simple
Type 1 (เป็นไปได้จริงในอนาคต)
If + Present Simple, will + V.1

Type 2 & Type 3

สมมติปัจจุบัน & เสียดายอดีต

ใช้สมมติในเรื่องที่ไม่จริงในปัจจุบัน หรือเสียดายเหตุการณ์ในอดีตที่แก้ไขไม่ได้

Type 2 (ตรงข้ามความจริงปัจจุบัน)
If + Past Simple (V.2 / were), would + V.1
Type 3 (ตรงข้ามความจริงในอดีต)
If + Past Perfect (had + V.3), would have + V.3
