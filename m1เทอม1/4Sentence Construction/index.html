3 ส่วนประกอบหลักของประโยค

S + V + O Layout

ประโยคบอกเล่าพื้นฐานในภาษาอังกฤษจะเรียงลำดับตามโครงสร้างตายตัว

1. Subject (ประธาน - ผู้กระทำ)
• คำนาม (Noun) หรือสรรพนาม (Pronoun) เช่น He, She, Cats, John
2. Verb (คำกริยา - การกระทำ)
• คำที่แสดงอาการหรือการกระทำ เช่น eat, play, read, write
3. Object (กรรม - ผู้ถูกกระทำ)
• สิ่งที่มารองรับการกระทำของประธาน เช่น an apple, football, books

ตัวอย่างการวิเคราะห์ประโยค

Examples

สังเกตการจับคู่คำศัพท์ในแต่ละตำแหน่งของประโยค

Example Analysis
• The cat (Subject) + catches (Verb) + a mouse (Object).
• Students (Subject) + read (Verb) + English books (Object).
