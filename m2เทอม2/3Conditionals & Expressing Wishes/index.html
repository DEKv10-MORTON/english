If-Clause Type 1 & Type 2 Cheat Sheet

เรียนรู้การสร้างประโยคเงื่อนไขที่เป็นไปได้จริงในปัจจุบัน/อนาคต (Type 1) และการสมมติตรงข้ามความจริง (Type 2)!

If-Clause Type 1 (Real Condition)

เป็นไปได้จริง

ใช้กับเหตุการณ์ที่เป็นเหตุเป็นผลกัน และมีโอกาสเกิดขึ้นจริงในปัจจุบันหรืออนาคต

โครงสร้าง (Structure)
If + Present Simple (V.1), Subject + will + V.inf
ตัวอย่าง (Example)
If it rains tomorrow, I will stay at home.
(ถ้าฝนตกพรุ่งนี้ ฉันจะอยู่บ้าน)

If-Clause Type 2 (Unreal Condition)

สมมติ/มโน

ใช้สมมติสิ่งที่ไม่เป็นจริงในปัจจุบัน หรือเป็นไปไม่ได้/เพ้อฝัน (Verb to be นิยมใช้ were กับทุกประธาน)

โครงสร้าง (Structure)
If + Past Simple (V.2 / were), Subject + would + V.inf
ตัวอย่าง (Example)
If I were rich, I would buy a sports car.
(ถ้าฉันรวย [แต่ตอนนี้ไม่รวย] ฉันจะซื้อรถสปอร์ต)
