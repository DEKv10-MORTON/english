Some vs. Any

Some (บอกเล่า) / Any (ปฏิเสธ-คำถาม)

ใช้ได้ทั้งนามนับได้พหูพจน์และนามนับไม่ได้

1. some (บ้าง / มีอยู่บ้าง)
• ใช้ในประโยคบอกเล่า: I have some water.
• ใช้ในประโยคขอร้อง/เสนอ: Would you like some tea?
2. any (เลย / บ้างไหม)
• ใช้ในประโยคปฏิเสธและคำถาม: I don't have any apples.

Much, Many & A lot of

Amount Expressions

คำบอกปริมาณมากน้อยตามประเภทคำนาม

Core Rules
• many + นามนับได้พหูพจน์: many books
• much + นามนับไม่ได้: much water (เน้นประโยคคำถาม/ปฏิเสธ)
• a lot of / lots of + ทั้งสองแบบ: ใช้ได้ทั้งบอกเล่า ปฏิเสธ คำถาม (เป็นทางการน้อยกว่า)
